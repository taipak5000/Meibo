# 名簿

職場や施設ごとに人物を登録し、あだ名・タグ・色で整理できる名簿アプリです。ブラウザで開くだけで使え、ホーム画面に追加すればアプリのように起動します。データは自分の端末の中にだけ保存され、外部のサーバーには送られません。

## 名前を思い出せなくても、あだ名や特徴から探せる

検索窓に入れた言葉は、名前、ふりがな、あだ名、特徴メモ、タグ名、場所名のすべてに対して照合されます。「ハナ」と打てば「はなちゃん」が、「眼鏡」と打てばメモに眼鏡と書いた人が出てきます。カタカナとひらがな、全角と半角の違いは自動で吸収するので、表記を揃える必要はありません。空白で区切れば複数の言葉での絞り込みになります。

## 場所とタグは自分で作る

「職場」「デイサービス」「○○教室」のように、人物の所属先を好きな名前で登録できます。1人を複数の場所に入れることもできます。タグは「女性」「月曜のみ」「要注意」など、場所をまたぐ目印として使います。一覧の上に並ぶチップを押すと場所で絞り込め、タグは複数選ぶとすべてに当てはまる人だけが残ります（AND検索）。

## 1人に登録できること

名前とふりがな、あだ名（いくつでも）、場所、タグ、色（13色から選択）、誕生日（年は省略可）、特徴メモ。色は一覧のカード左端とアイコンに反映されるので、色だけでも見分けがつきます。誕生日を入れておくと、7日以内に誕生日を迎える人が一覧の上部に表示されます。

## 並び替えと編集

並び順は「手動」「名前順」「誕生日が近い順」「追加が新しい順」「更新が新しい順」から選べます。手動のときは、右上の「編集」を押して右端のハンドルをドラッグすると、指の動きに追従して順番を入れ替えられます。削除も編集モードの赤いボタンから行い、消した直後の数秒間は「元に戻す」で復元できます。場所ごとにまとめて表示する切り替えもあります。

## ホーム画面への追加

iPhoneでは Safari で公開URLを開き、共有ボタン →「ホーム画面に追加」を選びます。Androidでは Chrome のメニュー →「ホーム画面に追加」または「アプリをインストール」です。一度開いたあとはオフラインでも起動し、サイト側を更新すると次に開いたときに裏側で自動的に最新版へ入れ替わります。

## データの保存先と引き継ぎ

登録した内容はブラウザ内のデータベース（IndexedDB）に保存されます。機種変更や別端末で使うときは、設定タブの「JSONで書き出す」でファイルを保存し、移行先で「JSONを読み込む」を実行してください。読み込み時は、今あるデータに足す「統合」と、まるごと入れ替える「置き換え」を選べます。ブラウザのデータを消去すると名簿も消えるので、バックアップとして定期的に書き出しておくことをおすすめします。

## 公開のしかた（GitHub Pages）

このリポジトリの内容をそのまま置き、Settings → Pages で公開するブランチを選ぶだけです。ファイルの参照はすべて相対パスなので、リポジトリ直下でも `meibo/` のようなサブフォルダでも動きます。構成は `index.html`（画面）、`style.css`（見た目）、`app.js`（動作）、`sw.js`（オフライン対応）、`manifest.json`（ホーム画面用の設定）、`icons/`（アイコン）です。
